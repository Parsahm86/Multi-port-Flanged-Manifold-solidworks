# Multi-port Flanged Manifold – SOLIDWORKS Design

A 3D CAD design exercise of an industrial multi-port flanged manifold (manifold), modeled in SOLIDWORKS.

This project was created as a self-challenge to practice complex surface modeling, multi-body feature creation, and standard industrial design workflows in SOLIDWORKS. The repository includes the original CAD files, a STEP model, and rendered images.

## Project Components

The manifold model consists of the following main geometric features:

1. **Circular Base Flange:** Provides mounting stability.
2. **Ribbed Multi-sided Body:** Adds structural strength and a complex visual geometry.
3. **Angled Cylindrical Ports:** Two outlet/inlet ports positioned at 90-degree angles.

## Selected Material

The component is designed to be manufactured using the following material:

| Component | Material |
|---|---|
| Main Body (Entire Part) | Aluminum 6061 Alloy |

*(Note: The material can easily be changed to stainless steel or cast iron depending on the required industrial application).*


## File Formats

- `SLDPRT` – Original SOLIDWORKS part file
- `STEP` – 3D model for universal compatibility with other CAD software (CATIA, NX, Fusion 360, etc.)
- `JPG` – SolidWorks viewport rendered images

## Software

- SOLIDWORKS (2025 or compatible version)
